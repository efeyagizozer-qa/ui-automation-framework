# UI Automation Framework

A modern UI test automation framework built with Java, Selenium WebDriver, Cucumber, and Maven.

This project was created to practice scalable automation framework design, reusable test architecture, and clean test organization using industry-standard tools.

---

## Tech Stack

- Java
- Selenium WebDriver
- Cucumber (BDD)
- Maven
- JUnit

---

## Current Framework Structure

```text
src
 ├── test
 │    ├── java
 │    │     └── com.efeozer
 │    │            ├── pages
 │    │            ├── stepdefinitions
 │    │            ├── utilities
 │    │            └── runners
 │    │
 │    └── resources
 │           ├── features
 │           └── configuration.properties
```
